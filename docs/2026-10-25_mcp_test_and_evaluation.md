# 2026-10-25 MCP 연결 테스트 · 보완 · 심리 예측력 검증

## 1. MCP(stock-graph) 연결 테스트
| 테스트 | 사용된 도구 | 결과 |
|---|---|---|
| 내 포트폴리오 부정 심리 종목 | get_latest_sentiment | 정상 (1건) |
| NVDA를 가장 많이 담은 ETF | run_cypher | 정상 (VOO 8.39% > SPY > QQQ > SOXX > VTI) |
| 반도체 섹터 분위기 (ask_stock_graph vs 직접 Cypher) | 둘 다 | 결론 동일. 직접 Cypher가 빠르고 미분석 종목까지 보여줌 |
| 쓰기 구문 차단 | run_cypher | DELETE/소문자/주석 우회/CREATE 모두 차단, READ 트랜잭션도 쓰기 거부 |

- ask_stock_graph는 내부에서 Claude를 2~3번 불러 15~30초 걸림. Cypher를 짤 수 있는 클라이언트에는 이점이 적고, Cypher를 모르는 클라이언트(웹 UI 등)용으로 의미가 있음.
- ETF 보유종목은 상위 종목만 저장 → "NVDA를 담은 ETF 전체"가 아니라 "NVDA가 상위 보유종목인 ETF"로 해석해야 함.

## 2. 발견한 문제와 보완
| 문제 | 보완 |
|---|---|
| 분석문이 매번 "평균 거래량 데이터가 없어 판단 어렵다"로 끝남 | 프롬프트에 직전 20거래일 평균 거래량과 배수 추가 (`AVG_VOLUME_DAYS`) |
| 분석문에 한자 혼입 (AMZN 10/23 "集中") | 시스템 프롬프트에 한자 금지 + 한자/일본어 검출 시 실패 처리 후 재시도. 기존 행은 "집중"으로 수정 |
| 삼성전자가 반도체 업종으로 안 잡힘 (yfinance: Consumer Electronics) | `universe.INDUSTRY_OVERRIDES`로 Semiconductors 보정, 업종 변경 시 기존 IN_INDUSTRY 삭제 후 재연결 |
| run_cypher 200행 초과 시 조용히 잘림 | 잘렸을 때 "전체 N행 중 200행" 안내 추가 |
| 분석이 있다 없다 하는 종목 설명 불가 | GraphRAG 스키마에 분석 대상 규칙(포트폴리오 + ETF 10 + 그날 거래량 Top 10) 명시 |

문제가 아니었던 것
- INTC는 포트폴리오 밖이지만 1부(거래량 Top 10)라서 분석됨. AMD/MU 등은 Top 10에 못 들어 미분석.
- "10/24 누락"은 오판. 2026-10-23이 금요일이라 마지막 거래일까지 다 채워져 있었음.
- 전체 배치 실행 결과 신규 분석 0건 (빈 날짜 없음). 새 프롬프트의 DB 적재는 10/26(월) 장 마감 이후 배치에서 확인 필요.

## 3. 심리 데이터의 예측력 검증 (279건, 2026-09-23 ~ 10-23)
- **심리 = 당일 등락의 재진술.** 긍정/부정이 당일 시가→종가 방향과 94% 일치 (긍정일 평균 +1.24%, 부정일 평균 -1.98%). 입력이 당일 시세뿐이라 새 정보가 없음.
- **다음 날 예측력 없음.**

| 심리 | 다음 날 평균 수익률 | 방향 적중률 |
|---|---|---|
| 긍정 | -0.80% | 38% |
| 부정 | -0.15% | 54% |
| 기준선 (다음 날 상승 비율) | | 46% |

- 표본이 한 달, 종목 간 상관이 커서 "역방향"이라 결론 내릴 수준은 아님. "예측력 근거 없음"까지가 결론.

## 4. 이력 데이터를 계속 쌓는 이유
1. 이런 검증 자체가 이력이 있어야 가능 (프롬프트 변경 전후 비교).
2. AI 판단은 재현 불가 (시세는 yfinance로 언제든 재수집 가능하지만 그날의 분석문은 아님).
3. 연속 부정, 심리 전환 같은 흐름 파악. 저장 비용은 하루 약 30행으로 무시할 수준.
